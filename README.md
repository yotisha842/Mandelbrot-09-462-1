# Множество Мандельброта — интерактивный фрактал

> Графическое Java-приложение для визуализации множества Мандельброта: полноцветный многопоточный рендер, масштабирование и панорамирование в реальном времени, экспорт изображений, собственный формат сохранения и анимированная «экскурсия» по фракталу.

Командный учебный проект (лабораторная работа №3, группа 09-461). Проектом руководила **Кристина Поздеева** — команда разработки из **12 человек**.

## О проекте

Множество Мандельброта — классический фрактал на комплексной плоскости. Для каждой точки `c` итеративно вычисляется последовательность `z → z² + c`: если она остаётся ограниченной, точка принадлежит множеству и окрашивается в чёрный; если «убегает» в бесконечность — цвет точки определяется тем, за сколько итераций это произошло. Приложение рисует эту картину в окне и позволяет исследовать фрактал интерактивно — приближаться к границе множества, где рождается бесконечная детализация.

## Стек

- **Java**, **Swing / AWT** — графический интерфейс, отрисовка, меню
- **Многопоточность** — параллельное вычисление изображения
- **Лямбда-выражения и интерфейсы** — сменные формулы фракталов и цветовые схемы
- Отдельный модуль-преобразователь координат (экранные пиксели ↔ комплексная плоскость), подключаемый как `.jar`

## Возможности

### Отрисовка и навигация
- **Полноцветный рендер** — цвет точки задаётся отдельными нелинейными формулами для каждого канала RGB в зависимости от доли пройденных итераций, что даёт насыщенное полноцветное изображение.
- **Масштабирование** выделенной рамкой области с сохранением пропорций — изображение не искажается ни при зуме, ни при изменении размеров окна.
- **Панорамирование** правой кнопкой мыши: зажатие, перемещение и сдвиг фрактала на пропорциональную величину при отпускании.
- **Динамическое число итераций** — автоматически растёт с приближением (от 50, когда фрактал виден целиком, до 2000 при сильном увеличении), с возможностью отключить через чекбокс в меню.

### Производительность
- **Многопоточная отрисовка** — изображение делится на горизонтальные полосы, которые распределяются между потоками (например, при 4 потоках строки 0/4/8… считает первый поток, 1/5/9… — второй и т. д.); потоки работают параллельно с синхронизацией.

### Сохранение и восстановление
- **Экспорт в JPG и PNG** через стандартный диалог сохранения, с автоматическим добавлением расширения и подписью координат отображаемой области на изображении.
- **Собственный формат `.frac`** — сохраняет все данные фрактала для точного восстановления; открытие через диалог с фильтром по `.frac`, после чего с фракталом можно продолжать работу (зум, сдвиг).
- **Отмена действий** — история масштабирования и сдвига на 100 шагов (`Ctrl+Z` и пункт меню).

### Расширенные возможности
- **Множество Жюлиа** — по клику на точке открывается отдельное окно со связанным фракталом Жюлиа; окно имеет собственное меню и поддерживает те же операции (зум, сдвиг, смена цвета).
- **Сменные формулы и цветовые схемы** — разные функции построения фракталов передаются в отрисовщик через лямбда-выражения, а цветовые схемы — через интерфейсы; выбор происходит из меню.
- **Экскурсия по фракталу** — анимированное плавное перемещение между заданными пользователем ключевыми кадрами: в отдельном окне добавляются/удаляются кадры, между ними достраиваются промежуточные (около 30 кадров в секунду), результат экспортируется в видеофайл.

### Интерфейс
- **Главное меню** (`JMenu`), объединяющее все операции с фракталом.

## Запуск

Проект оформлен как проект IntelliJ IDEA (JDK, библиотеки в папке `lib/`).

1. Открыть проект в IntelliJ IDEA.
2. Убедиться, что подключены библиотеки из `lib/` (включая модуль-преобразователь координат).
3. Запустить главный класс приложения из `src/`.
